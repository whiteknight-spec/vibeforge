# 🚀 Vibeforge

A modern, fast, and responsive cross-platform mobile application built using **Flutter**. Designed to provide a smooth and intuitive user experience on Android devices.

---

## 📱 Features

- ✨ **Fast & Lightweight:** Optimized build with minimal APK size.
- 🎨 **Clean UI/UX:** Modern, clean, and responsive design.
- ⚡ **Cross-Platform Base:** Built on Flutter framework for robust performance.
- 🔒 **Secure & Reliable:** Stable architecture with modern Android standard compliance.

## 🛠️ Tech Stack & Requirements

- **Framework:** [Flutter](https://flutter.dev/)
- **Language:** [Dart](https://dart.dev/)
- **Target OS:** Android 10+ (Tested on Android 14 / Android 15)
- **Supported Architecture:** `arm64-v8a`, `armeabi-v7a`, `x86_64`
